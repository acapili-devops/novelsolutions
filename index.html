PRODUCTS & SOLUTIONS

JAVELIN J800 EX

Description

The NorthStar Javelin J800 EX is a compact, 200 MHz semiconductor Automated Test Equipment (ATE) system designed to test integrated circuits (ICs). It supports configurable digital, analog, and mixed-signal testing, making it suitable for semiconductor test development and production environments.

Key Features

  • 200 MHz digital test capability
  • Configurable analog and mixed-signal testing
  • Compact and modular design for easy integration
  • Supports a wide range of semiconductor devices
  • User-friendly software interface for test development
ENGINEERING SOLUTIONS

JAVELIN J800 MX2

Description

The NorthStar Javelin J800 MX2 is a semiconductor Automated Test Equipment (ATE) system designed for high-capacity, high-parallelism integrated circuit (IC) testing. It combines configurable digital and analog test capabilities in a compact platform for semiconductor engineering and manufacturing.

Key Features

  • 1536 I/O channels full digital tester,
  • 68-channel full analog tester,
  • Mix signal tester
